# **Что это за приложение**

Это Android-приложение, в котором можно искать музыку через iTunes, слушать отрывки треков, добавлять их в избранное и создавать свои плейлисты. В приложении есть светлая и темная тема.

# Какие технологии использовал

Архитектура построена на MVVM с разделением на слои data, domain и presentation. Для асинхронной работы использовал корутины и Flow.

Из библиотек: Room для хранения избранных треков и плейлистов, Retrofit с OkHttp для запросов к iTunes API, Koin для внедрения зависимостей.

Для интерфейса использовал ViewBinding, Navigation Component, ViewPager2 с вкладками, BottomSheetBehavior для выезжающего списка треков, RecyclerView с адаптерами и DiffUtil для эффективного обновления списков. Картинки загружаю через Glide.

Медиаплеер работает на базе MediaPlayer, историю поиска и настройки темы сохраняю в SharedPreferences. Для шеринга плейлиста использую стандартный системный Intent.

# Что умеет приложение

Искать треки по названию через iTunes API (с задержкой между вводом, чтобы не спамить запросами). Проигрывать 30-секундный отрывок трека. Добавлять треки в избранное и убирать их оттуда. Создавать новые плейлисты, редактировать их название, описание и обложку. Добавлять треки в плейлисты и удалять их оттуда с подтверждением. Делиться плейлистом — в сообщение уходит название, описание, количество треков и их нумерованный список с исполнителем, названием и длительностью. Переключать светлую и темную тему, причём выбор сохраняется.

Пара интересных моментов в реализации

Список треков в плейлисте сделан в виде Bottom Sheet, который нельзя скрыть полностью, но можно растянуть на весь экран. Перетаскивать его можно только за специальный индикатор, а когда тянешь пальцем по списку — прокручиваются только треки.

Треки в плейлисте сортируются по дате добавления: последние добавленные оказываются сверху.

Приложения запоминает, что вы вводили в поиске, и сохраняет историю.

Обложки плейлистов копируются во внутреннее хранилище приложения, чтобы они не терялись и не зависели от оригинальных файлов.
